Step 1: Create a Checkout Session
=================================
POST ==> https://creditlibanais-netcommerce.gateway.mastercard.com/api/rest/version/100/merchant/<YOUR_MERCHANT_ID>/session

Authentication
--------------------
Basic HTTP authentication as described at w3.org. Provide 'merchant.<YOUR_MERCHANT_ID>' in the userid portion and your <API password> generated in your MPGS portal, in the password portion.

Request body (JSON object)

Step 4: Thank you Page
=======================
When returning to merchant website (in data-complete callback function)
At this step, make a request to "Retrieve order" and check for the result of payment using the OrderID parameter returned as a QueryString in the returnURL

GET ==> https://creditlibanais-netcommerce.gateway.mastercard.com/api/rest/version/100/merchant/<YOUR_MERCHANT_ID>/order/<YOUR_ORDER_ID>;

Authentication
---------------
Basic HTTP authentication as described at w3.org. Provide 'merchant.<YOUR_MERCHANT_ID>' in the userid portion and your API password in the password portion.

Request body (empty)

N.B: To consider the payment as successful, check the following two parameters obtained from the "Retrieve Order" operation response:

"result" should be "SUCCESS"
"status" should be "CAPTURED"

Display the Order ID, Amount with the Currency and a successful payment message for the customer.
