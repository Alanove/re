✨ New Features Added:

  • Active State Icons: Toolbar buttons now show active state when text has that formatting (bold, italic, etc.)
  • Better Alignment Icons: Clearer icons for text alignment (left, center, right, justify)
  • Full Width HTML Mode: HTML source textarea now takes full width of container
  • Clearer List Icons: Better icons for bulleted and numbered lists
  • Custom Modals: Professional modals for inserting links and images (no more browser prompts!)
  • Image Upload: Upload images directly from your computer using the same handler as Quill
