Self-hosted captcha playground

This page runs the real @local/captcha code. The server issues a signed challenge, the browser finds the hidden number in a Web Worker (a few hundred milliseconds), and the server checks the answer. No Google or Cloudflare account, no keys to create, no limits. The page uses a strict Content Security Policy, the same as the sites.

Settings

1. Normal form (like the contact form)

Posts the page the classic way. The widget holds the submit until the token is ready.

Please enable JavaScript to send this form.

2. Fetch form (sends without reloading)

Uses SiteCaptcha.getToken(form), then posts JSON. Send it twice: each send gets a fresh token.

Please enable JavaScript to send this form.

3. Admin login style

Its own scope (admin-login), so a contact token can't be used here and the other way round.

Please enable JavaScript to sign in.

Try to cheat

Each button sends a bad request to the contact scope. The server should reject every one of them.
